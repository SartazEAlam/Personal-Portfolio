# Sartaz E Alam — Personal Portfolio

A personal portfolio website built to showcase my skills, projects, and background. Submitted as **Task 1** for the **Saiket System** Web Development Internship.

## Features

- Responsive navbar with smooth scroll navigation
- Animated hero section with a code-themed card
- Skills grid with icons (Frontend, Backend, Tools)
- Project cards for SkillBarter and ShopNext
- Education and contact sections
- Scroll-triggered fade-up animations

## Tech Stack

- HTML5, CSS3, JavaScript
- Bootstrap 5
- Google Fonts (Inter, Poppins)
- DevIcons

## Project Structure

```
portfolio/
├── index.html
├── style.css
├── script.js
├── Sartaz_E_Alam_CV.pdf
└── images/
```

## Getting Started

Open `index.html` in any browser. No build steps required.
